# 管理用棋譜アーカイブ（archive-v1）

新しい画面で「棋譜提供に協力して遊ぶ」を選んだ対局を対象とする。「プライベートで遊ぶ」はサーバーへ棋譜を送信せず、保存・引き継ぎ・個人の履歴による学習を行わない。画面を閉じると対局は失われる。匿名ユーザー、ログインユーザー、チェス、大将棋、2人対戦、未完了対局を含む。初手を指した時点で対局を作成する。サーバーが受理した更新ごとに `game_archive` に棋譜全体を追加する。待った前の手も別リビジョンとして残る。盤面操作は保存完了まで待つ。通信断・保存失敗時は進行を停止し、画面の再開操作で再試行する。ブラウザを保存完了前に閉じた場合など、サーバー未受信の手まで保証しない。

アーカイブに自動の期限削除は設けない。`games` は本人の再開・学習用の現在棋譜で、学習は最新50対局を参照する。履歴削除とアカウント削除では `games` を削除し、外部キーの `ON DELETE SET NULL` によりアーカイブの `game_id` を外す。アーカイブは独立したランダムな `archive_key` で対局内のリビジョンだけをまとめる。氏名、メール、IP、プレイヤーID、ログインハッシュ、セッションIDはアーカイブに含まれない。利用者向けAPIにアーカイブ取得経路はない。

旧90日方針の既存データは自動で移行しない。新方針に同意して再開・保存した時点からアーカイブする。旧画面からの新規作成・更新は428で再読み込みを要求する。従来記録しなかった対局や、既に削除・上書きされた履歴は復元できない。

## 管理側での取得

Cloudflareの `shimajima-eiji` アカウント（account_id は wrangler.jsonc で固定）のD1コンソールで `nomuraya-chess-room` を開く。全ユーザーの完了・未完了記録は `game_archive` にある。必要なときに認証済みWranglerから `scripts/archive-export.sql` を実行することもできる。

```sh
npx wrangler d1 execute nomuraya-chess-room --remote --file scripts/archive-export.sql --json
```

出力は非公開の管理データ。公開リポジトリへの保存・コミットは禁止。件数だけ調べる場合は `SELECT COUNT(*) AS revisions, COUNT(DISTINCT archive_key) AS games FROM game_archive;` を使う。大量になったら取得をidで分割する。全対局のバックアップ転送、管理画面、定期エクスポートは未実装。D1の容量・課金は既存プランに従う。
