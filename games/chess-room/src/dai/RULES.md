# 採用ルール dai-v1

2026-09-05に資料を照合した15×15の大将棋。平安大将棋・大大将棋とは別。
史料や現代の再構成には差があるため、以下をこの実装の裁定とする。

資料:
- [Eric Silverman: Dai Shogi, Part I](https://drericsilverman.com/2020/04/13/dai-shogi-part-i-how-to-play/): 現代プレイヤーによる解説、成り・獅子・反復の整理。
- [Dai shogi](https://en.wikipedia.org/wiki/Dai_shogi): 初期配置・駒の動きの照合、反復と成りの異説確認。一次史料そのものではない。
- [GNU Shogi manual](https://www.gnu.org/software/gnushogi/manual/Shogi-variants.html): 大将棋の盤と駒数の照合。
- Chess Variant Pagesは取得制限により全文を確認できず、直接の検証済み出典とはしていない。

## 盤・動き・成り

各65枚、持ち駒・駒打ちはない。先手は下、後手は180度回転した配置。
王将と玉将の動きは同じ。駒を越えられるのは跳躍を持つ駒の指定方向のみ。
猛牛・飛龍は2マスまでの走りであり、途中の駒を越えない。
獅子は周囲2マスへの跳躍、1歩ずつ2回の移動・二枚取り・居喰い・空所を経由して戻るパス。
角鷹は真前、飛鷲は斜め前の同じ直線上に限定した獅子の動きを持つ。
中将棋の獅子交換制限は採用しない。

成りは、敵側の奥5段に外から入ったとき、または出発/到着地点がその区域にある駒取りで任意。
一度成った駒は再度成らない。仲人から成った酔象は太子に再成りしない。
不成の駒が区域内を進むだけでは再び成れず、駒取りか区域外からの再進入が必要。
最奥段での追加成り機会と強制成りは採用しない。動けない駒はそのまま盤に残る。

## 終局・反復の裁定

相手の王駒（玉将/王将/太子）をすべて取れば勝ち。王手放置・王手への移動は許容。
移動可能な手がなくなった側も負け。裸玉だけでの自動勝利は採用しない。
盤面と手番が過去と一致する手は禁止。王手中の例外・4回反復の裁定は採用しない。
これらは解釈を固定したアプリのルールで、唯一の歴史的正解とは主張しない。

## 実装対応

`engine.ts` の `specs` が全駒の方向・射程・跳躍・成り先を定義。
`Piece.kind` は元の駒種を保存し、`promoted` は一度だけの成りを保持する。
棋譜は `from`, `path`（1〜2地点）, `promote`。経路途中の駒取りも保存し再生できる。
同じ着地でも取る駒が異なる経路をUIで選択できる。空所を通るだけの同等経路は表示をまとめる。

入門用AIと個人モデルを提供するが、棋力や学習効果の保証はない。
